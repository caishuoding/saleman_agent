# 销售培训产品讨论记录

首版功能范围已于 2026-11-12 由用户整体确认。后续页面设计和技术方案以本文为范围依据。

2026-11-12 界面讨论补充确认：提供独立的项目资料入口，包含多个产品的资料；各专项可选择推销的产品。模拟客户为案例中的甲方负责人，其职务与职责随产品和案例确定。

## 使用者与使用方式

- 面向销售新人，供学员自主练习销售沟通，训练记录由本人回看。
- 第一版采用电脑浏览器中的网页版，使用文字交互。
- 第一版先在用户电脑本地运行，通过浏览器访问，后续再讨论部署与分享访问。
- 系统采用前后端分离架构，后端使用 Python 与 LangGraph。
- 第一版免登录，练习对话、教练交流、复盘内容和完整练习进度由后端保存在 PostgreSQL，前端通过 API 访问训练记录。

## 训练内容

- 首个业务背景采用企业软件销售，项目资料支持多个产品，虚构 CRM 可作为其中一个产品示例。具体产品名单与内容待编定。
- 产品资料、客户背景、业务情境及各练习必要的前情由我们预先编定。
- 提供独立的“项目资料”入口，集中展示多个产品的资料；学员可在练习前学习，并在练习中查阅当前产品资料。
- 每次练习采用一个模拟客户，代表甲方的具体负责人。学员扮演产品销售，通过自由对话开展沟通；甲方负责人的具体职务、业务职责及项目职责随产品和案例设定。
- 模拟客户围绕当前练习内容回应，客户记忆限定在该次练习内。
- 需求沟通中的客户根据学员提问自然回应，逐步讲清具体情况。

## 专项练习

- 提供“需求沟通与方案介绍”和“商务谈判与合作推进”两个专项入口。
- 需求沟通与方案介绍在同一专项内自然交替进行。商务谈判与合作推进聚焦价格、付款、服务条件、采购流程和下一步安排。
- 学员选择专项后，选择本次推销的产品，再进入对应专项与产品的预设情境。
- 各专项模块独立，客户记忆与对话记录按练习隔离。
- 专项所需的需求、初步方案或商务条件由案例预先编定。各专项开练时创建独立会话。
- 专项练习也可保留未完成记录，并从历史记录、收藏或首页最近未完成练习入口继续。
- 异议处理、跟进和确认下一步融入对应专项的具体情境。

## 完整练习

- 提供一个独立的“完整流程练习”入口，围绕同一客户案例串联销售全流程。
- 开练前的任务说明展示“需求沟通与方案介绍 → 商务谈判与合作推进”的参考流程。
- 学员根据客户反应自然推进，在同一场对话中沟通各环节，并沿用该场练习内的前文和约定。
- 支持中途退出并保存进度，下次恢复此前的对话与客户状态继续练习。

## 教练与复盘

- 练习中，学员可主动向训练教练求助，获得针对当前对话的提示，再继续与模拟客户沟通。
- 学员主动点击“结束练习”结束当前对话，随后进入复盘。
- 复盘页采用三栏布局，左侧为原始聊天记录，中间为复盘总结，右侧为可提问的教练助手。
- 当前确认复盘的布局和交互入口。总结内容、生成方式及教练回复的具体实现留待后续设计，原型使用占位内容。
- 首版取消逐字引用与点击定位原始消息的要求。
- 学员可继续与训练教练对话，追问原因、请求解释或替代说法。

## 重练与历史记录

- 第一版重练采用同一个案例从头开始的方式，模拟客户恢复案例初始状态，学员重新进行一次独立练习。
- 保存每次练习的对话和复盘内容，供学员回看。
- 学员可从历史记录打开原案例，恢复案例初始状态并发起重练。
- 历史记录展示每次练习的开始日期和时间，开始时间以学员点击“开始练习”为起点。续练沿用原开始时间，重练产生新的开始时间。
- 学员可收藏或取消收藏某次练习，在独立的“收藏”入口查看对应记录，并打开同一次练习。
- 历史记录和收藏列表展示练习名称、产品、练习类型、开始时间与状态。甲方为预设角色，列表省略甲方公司和姓名。
- 历史记录和收藏均支持重命名单次练习。保存后的名称同步显示在对应记录入口，取消编辑保留原名称。
- 收藏列表提供“删除”操作，确认弹窗明确说明将移出收藏且保留历史记录。
- 历史记录和收藏均支持按已完成、未完成、练习类型及产品项目组合筛选。练习类型包含两个专项及完整流程练习，项目选项对应项目资料中的各产品。

## 页面与操作流程

- 训练首页展示两个专项和完整流程练习入口。进入具体专项后再选择产品。续练卡片展示按开始时间最近的一次未完成练习，范围包含专项和完整流程练习。
- 主导航提供独立的“项目资料”入口，展示产品列表并支持进入各产品查看资料。
- 选择专项后先选择推销产品，再查看任务、甲方公司、具体负责人及其职责；点击“开始练习”后与模拟客户对话。
- 练习页以客户聊天为中心，提供“查看资料”“问教练”“结束练习”操作。
- 点击“问教练”后，在客户聊天右侧展开教练对话。客户和教练区域分别标明对象，各自的输入框向对应对象发送消息。
- 点击“结束练习”时，提示将结束本次客户沟通并进入复盘，由学员确认后执行。
- 复盘页同时展示原始聊天记录、复盘总结和教练问答，提供收藏及“重新练习”操作。
- 历史记录页展示开始日期和时间、产品、练习类型及状态，支持收藏、取消收藏、继续未完成的练习，以及回看已完成的对话与复盘。
- 主导航提供独立的“收藏”入口。收藏关联原练习记录，取消收藏后原历史记录继续保留。

## 模型接入

- 首版文字对话使用 DeepSeek Flash，模拟客户、训练中求助、复盘及复盘追问均使用该模型。
- 官方模型标识为 `deepseek-flash`。模型名称已于 2026-11-12 对照 [DeepSeek 官方模型文档](https://api-docs.deepseek.com/quick_start/pricing/) 核实，接入时以官方最新文档为准。
- 语音模型接入安排在后续迭代，具体语音服务和交互方式届时再讨论。
