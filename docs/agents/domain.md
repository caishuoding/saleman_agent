# 领域文档

本项目采用单领域结构。

- 领域术语位于根目录 `GLOSSARY.md`。
- 架构决策记录位于 `docs/adr/`。
- 已确认的产品范围位于 `docs/product-scope.md`。

## 读取规则

探索项目之前，读取术语表及与当前工作相关的架构决策。
涉及产品功能或训练流程时，读取产品范围记录。
仅对实际存在的文件执行读取，随后继续当前工作。

## 使用规则

输出中的领域概念沿用术语表定义。
遇到需要澄清或新增的术语，由 domain-modeling 在含义确定后记录。
架构决策记录按实际需要创建。
提出与既有架构决策冲突的方案时，明确指出冲突及重新讨论的理由。
