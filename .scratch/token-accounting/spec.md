# Tokenizer 与真实用量记录

用户要求使用 tokenizer 并记录真实 token。继承已确认的公开 HTTP 测试入口。

- 使用与 deepseek-flash 当前 V4.1 模型对应的 DeepSeek 官方 tokenizer 和完整消息模板计算调用前输入、摘要和活动窗口 token。
- 默认启用可复现的本地 tokenizer 资源，移除 UTF-8 字节估算回退。
- 每次模型网络调用（情境、客户、教练、复盘、摘要与重试）分别保存本地输入计数及 API usage，包括输入、输出、总量及缓存等原始字段。
- API usage 是服务端实际用量依据。缺失用量明确标记未知，失败或中断保存已经收到的统计。
- 并发请求的用量互不覆盖。幂等重放不重复计费记录，实际重试独立记录。
- 提供公开 HTTP 查询单场调用明细及累计统计，保持现有 UI 和两个独立 Agent 流程。
- 运行相关接口测试、类型与规范检查，完成审查并提交。
