# 按练习类型准备客户上下文

依据本次对话中确认的流程实现。

- 需求沟通与方案介绍、完整流程练习共用背景生成流程。输入所选产品名称及完整资料，生成真实可信的虚构公司业务、规模、工作方式、具体问题、影响及负责人身份，问题须与产品实际能力相关。
- 背景生成提示词描述案例编写任务，生成公开背景和隐藏需求，不再要求生成初始认知。客户在正式对话中根据销售介绍逐步了解产品。
- 生成结果保存在本场练习中，公开接口仅展示公司及负责人基本信息，隐藏需求只进入客户上下文。准备失败可重试，成功后重复请求复用结果。
- 商务谈判与合作推进在选择产品时直接创建练习，采用通用采购负责人身份，不调用模型生成背景。客户每轮请求获得本场产品资料快照，并站在采购方立场讨论价格、付款、服务、交付及合作条件。
- 完整流程沿用同一客户、同一背景和本场对话中的认知与约定，自然推进到商务谈判。
- 练习由学员先发言。续练与重练保留对应练习的初始上下文，兼容已有记录。
- 前端按类型显示准备状态。商务练习展示产品及采购方身份，需求与完整流程保留客户背景展示。
