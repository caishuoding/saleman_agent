# 前端发送与窗口适配

- 客户聊天、练习中教练与复盘教练均支持 Enter 发送，Shift+Enter 换行，兼容原有 Ctrl/Command+Enter。
- 中文输入法确认候选时不发送，长按 Enter、空白输入与生成期间不重复提交。
- 根据实际可用窗口尺寸分配聊天高度，消息可滚动，输入与操作始终可达。
- 窄窗口下聊天与教练、复盘各区域顺序排列，可滚动查看全部内容。
- 资料弹窗、任务详情、长文本与导航适配窄窗口和矮窗口，保留必要标签与危险操作后果提示。
- 浏览器回归通过真实页面操作与隔离 API 数据验证，沿用后端测试边界运行全量测试。
